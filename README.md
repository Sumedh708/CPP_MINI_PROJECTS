## 🔨 How to Run

1. **Install the compiler:** Install the respective C++ compiler (`g++`) depending on your OS.
2. **Compile the code:** Open your terminal in the project folder and run:
   ```bash
   g++ main.cpp -o main
3. **Run the executable: **
   Windows:
    ```bash
      main.exe
   Linux:
     ```bash
      .\main
